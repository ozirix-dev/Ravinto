อมารันท์เป็นกลุ่มพืชที่น่าสนใจทั้งด้านคุณค่าทางอาหาร สุขภาพของมนุษย์ การเพาะปลูก และอนาคตของการผลิตอาหาร พืชชนิดนี้ไม่ได้เป็นเพียงพืชทดแทนธัญพืชเท่านั้น เพราะสามารถใช้ประโยชน์จากเมล็ด ใบ ยอดอ่อน น้ำมัน และรงควัตถุธรรมชาติได้ บางพันธุ์เติบโตเร็ว ทนร้อน และทนแล้งได้ดี

องค์ประกอบกรดอะมิโนในเมล็ด สควาลีนในน้ำมัน และรงควัตถุเบตาเลนในใบสีแดงเป็นประเด็นที่ได้รับความสนใจ อมารันท์สามารถปลูกในประเทศไทยได้เช่นกัน แต่การผลิตใบและการผลิตเมล็ดมีวิธีปฏิบัติที่แตกต่างกัน

## 1. สรุปประเด็นสำคัญ {#summary}

| คุณสมบัติ | การประเมิน |
| --- | --- |
| คุณค่าทางโภชนาการ | เด่นด้านโปรตีนและแร่ธาตุในเมล็ด |
| โปรตีน | ประมาณ 13–16% ของเมล็ดแห้ง |
| สารสำคัญ | สควาลีนในน้ำมันเมล็ด |
| กลูเตน | ปราศจากกลูเตนตามธรรมชาติ |
| ความทนแล้งและทนร้อน | ดีเมื่อพืชตั้งตัวแล้ว |

| การปลูกในประเทศไทย | มีศักยภาพ โดยเฉพาะการปลูกเป็นผักใบ |

| หลักฐานด้านผลสุขภาพเฉพาะ | เป็นอาหารมีคุณค่า แต่ยังไม่ใช่ยาที่ได้รับการพิสูจน์ |

จุดเด่นของอมารันท์คือการรวมคุณสมบัติหลายด้านไว้ในพืชชนิดเดียว ทั้งมีคุณค่าทางอาหาร ใช้ประโยชน์ได้หลากหลาย และปลูกได้ค่อนข้างง่ายในสภาพแวดล้อมหลายแบบ อย่างไรก็ตาม ข้อกล่าวอ้างด้านสุขภาพจากสารเฉพาะในพืชมักหนักแน่นกว่าหลักฐานจากการศึกษาในมนุษย์

## 2. อมารันท์คือพืชอะไร? {#plant}

Amaranthus เป็นสกุลพืชในวงศ์ Amaranthaceae มีหลายสิบชนิด อยู่ในวงศ์เดียวกับพืชอย่างควินัว ผักโขม และบีตรูต อมารันท์ส่วนใหญ่เป็นพืชล้มลุกอายุปีเดียว ความสูงมีตั้งแต่หลายสิบเซนติเมตรไปจนถึงมากกว่าสองเมตร ขึ้นกับพันธุ์และสภาพการปลูก

อมารันท์หลายชนิดใช้การสังเคราะห์แสงแบบ C4 ซึ่งช่วยให้เติบโตได้มีประสิทธิภาพในอากาศร้อนและแสงแดดจัด จึงเป็นพืชที่น่าสนใจต่อการเกษตรที่ต้องปรับตัวกับการเปลี่ยนแปลงสภาพภูมิอากาศ

### ชนิดที่นิยมปลูก

| ชนิด | การใช้ประโยชน์หลัก |
| --- | --- |
| Amaranthus cruentus | เมล็ดและใบ |
| Amaranthus hypochondriacus | เมล็ดและแป้ง |
| Amaranthus caudatus | เมล็ด ไม้ประดับ และใบ |
| Amaranthus tricolor | ผักใบ มีทั้งพันธุ์แดงและเขียว |
| Amaranthus dubius | ผักใบ โดยเฉพาะในเขตร้อน |
| Amaranthus viridis | ใบรับประทานได้ และพบขึ้นเองตามธรรมชาติ |

อมารันท์ที่ปลูกเพื่อเมล็ดจะมีช่อดอกขนาดใหญ่และมีเมล็ดเล็กจำนวนมาก ส่วนอมารันท์ที่ปลูกเป็นผักจะใช้ใบสีเขียวหรือสีแดง

### ประวัติโดยย่อ

อมารันท์มีประวัติการเพาะปลูกยาวนานหลายพันปี ชนพื้นเมืองในอเมริกากลาง รวมถึงชาวแอซเท็ก ใช้เป็นพืชอาหารสำคัญ และพืชชนิดนี้ยังมีบทบาทในภูมิภาคแอนดีสด้วย ต่อมาอมารันท์แพร่เข้าสู่ยุโรป ซึ่งในช่วงแรกนิยมปลูกเป็นไม้ประดับมากกว่าเป็นอาหาร

ปัจจุบันมีการปลูกอมารันท์ในอเมริกากลางและอเมริกาใต้ อินเดีย จีน เอเชียตะวันออกเฉียงใต้ และหลายประเทศในแอฟริกา ในทวีปอเมริกาให้ความสำคัญกับเมล็ดเป็นพิเศษ ขณะที่หลายพื้นที่ในเอเชียและแอฟริกาใช้ใบเป็นอาหารอย่างแพร่หลาย

## 3. คุณค่าทางโภชนาการ {#nutrition}

ควรแยกข้อมูลระหว่างเมล็ดแห้ง เมล็ดต้ม และใบสด เพราะปริมาณต่อ 100 กรัมแตกต่างกันมาก โดยเฉพาะเมล็ดต้มที่ดูดซึมน้ำ

### องค์ประกอบโดยประมาณต่อ 100 กรัม

| สารอาหาร | เมล็ดแห้ง | เมล็ดต้ม | ใบสด |
| --- | ---: | ---: | ---: |
| พลังงาน | 371 kcal | 102 kcal | 23 kcal |
| โปรตีน | 13.6 g | 3.8 g | 2.5 g |
| ไขมัน | 7.0 g | 1.6 g | 0.3 g |
| คาร์โบไฮเดรต | 65.2 g | 18.7 g | 4.0 g |
| ใยอาหาร | 6.7 g | 2.1 g | — |
| แคลเซียม | 159 mg | 47 mg | 215 mg |
| ธาตุเหล็ก | 7.6 mg | 2.1 mg | 2.3 mg |
| แมกนีเซียม | 248 mg | 65 mg | 55 mg |
| โพแทสเซียม | 508 mg | 135 mg | 611 mg |
| โฟเลต | 82 µg | 22 µg | 85 µg |

ค่าประมาณที่ปัดเศษจาก [USDA FoodData Central](https://fdc.nal.usda.gov/) ปริมาณจริงแปรผันตามพันธุ์ สภาพการปลูก และการแปรรูป ค่าต่อ 100 กรัมของเมล็ดต้มลดลงส่วนใหญ่เพราะเมล็ดดูดซึมน้ำ

### 3.1 โปรตีน

เมล็ดอมารันท์แห้งมักมีโปรตีนประมาณ 13–16% จุดเด่นคือมีไลซีน ซึ่งเป็นกรดอะมิโนจำเป็นที่มีค่อนข้างน้อยในธัญพืชบางชนิด เช่น ข้าวสาลี ข้อมูลอ้างอิงของ USDA ระบุว่าเมล็ดแห้ง 100 กรัมมีไลซีนประมาณ 0.75 กรัม

อมารันท์จึงช่วยเสริมโปรตีนในอาหารที่พึ่งพาธัญพืชเป็นหลักได้ คุณภาพโปรตีนยังขึ้นกับการปรุง การย่อย และการดูดซึมด้วย

### 3.2 แร่ธาตุ

เมล็ดอมารันท์มีแมกนีเซียมและธาตุเหล็กในระดับที่น่าสนใจ ธาตุเหล็กมีความสำคัญต่อการขนส่งออกซิเจน แต่การดูดซึมธาตุเหล็กชนิดไม่มีฮีมจากพืชแปรผันได้ ไฟเตตและออกซาเลตในอมารันท์อาจลดการดูดซึมแร่ธาตุบางชนิด ดังนั้นตัวเลขในตารางองค์ประกอบอาหารจึงไม่เท่ากับปริมาณที่ร่างกายดูดซึมได้จริง

### 3.3 ใบและวิตามิน

ใบอมารันท์เป็นผักพลังงานต่ำและมีสารอาหารหลายชนิด ข้อมูล USDA สำหรับใบดิบ 100 กรัมระบุโดยประมาณว่ามีวิตามินซี 43.3 mg วิตามินเค 1,140 µg วิตามินเอ 146 µg RAE โฟเลต 85 µg แคลเซียม 215 mg และโพแทสเซียม 611 mg

วิตามินซีลดลงเมื่อปรุงสุก และออกซาเลตอาจจำกัดการดูดซึมแร่ธาตุบางชนิด คุณค่าของใบจึงมาจากการรวมกันของวิตามิน แร่ธาตุ รงควัตถุพืช และพลังงานต่ำ

## 4. สารประกอบที่มีลักษณะเฉพาะ {#compounds}

### 4.1 สควาลีน

สควาลีนเป็นสารไฮโดรคาร์บอนตามธรรมชาติ พบได้ทั้งในพืช สัตว์ และร่างกายมนุษย์ เป็นส่วนหนึ่งของกระบวนการสร้างคอเลสเตอรอลและสเตอรอลชนิดอื่น และยังพบในน้ำมันจากต่อมไขมันของผิวหนัง มีการศึกษาการใช้เป็นวัตถุดิบในอุตสาหกรรมเครื่องสำอาง อาหาร และยา อมารันท์เป็นหนึ่งในแหล่งจากพืช

การศึกษาจีโนไทป์อมารันท์ 104 แบบรายงานว่าปริมาณน้ำมันในเมล็ดเฉลี่ยประมาณ 5.0% (ช่วง 1.9–8.7%) สควาลีนคิดเป็นเฉลี่ย 4.2% ของน้ำมัน และสูงถึง 7.3% ในบางตัวอย่าง หากคำนวณจากค่าเฉลี่ย เมล็ด 100 กรัมจะมีน้ำมันประมาณ 5 กรัม และสควาลีนราว 210 mg นี่เป็นเพียงตัวอย่างคำนวณ ไม่ใช่ค่าคงที่ของทุกพันธุ์ สควาลีนกระจุกตัวอยู่ในน้ำมัน ไม่ใช่มวลเมล็ดทั้งหมด ส่วนใบมีสควาลีนน้อยกว่ามาก

งานวิจัยศึกษาคุณสมบัติทางเคมี การเกิดออกซิเดชัน การทำงานของผิวหนัง และการใช้ทางเภสัชกรรม บทบาททางชีวภาพของสารนี้ไม่ได้พิสูจน์ว่าการกินอมารันท์ป้องกันมะเร็ง ยืดอายุ หรือรักษาโรคหัวใจ สควาลีนไม่ใช่สารอาหารจำเป็นที่ต้องได้รับจากอมารันท์

### 4.2 เบตาเลน

สีสดของอมารันท์แดงเกิดจากเบตาเลน โดยเฉพาะเบตาไซยานินสีแดงม่วง สารสีที่เป็นเอกลักษณ์ชนิดหนึ่งคืออะมารันทิน เบตาเลนมีโครงสร้างทางเคมีต่างจากแอนโทไซยานินในบลูเบอร์รี แม้ทั้งสองกลุ่มจะให้สีแดงหรือม่วงได้

การทดลองในห้องปฏิบัติการพบคุณสมบัติต้านออกซิเดชัน แต่หลักฐานในมนุษย์ยังไม่เพียงพอที่จะสรุปว่าสีจากอมารันท์ป้องกันโรคเรื้อรังได้อย่างมีนัยสำคัญ ปริมาณรงควัตถุแตกต่างกันมากในแต่ละพันธุ์

| เปปไทด์ออกฤทธิ์ทางชีวภาพ | งานวิจัยระดับห้องปฏิบัติการ เช่น ผลต่อเอนไซม์ |
| ใยอาหาร | สนับสนุนการย่อยอาหารและความอิ่ม |

ความเครียดจากความร้อน ความแห้ง หรือความเค็มอาจเปลี่ยนระดับสารป้องกันตัวในพืช แต่การมีสารเข้มข้นขึ้นไม่ได้แปลว่าอาหารปลอดภัยหรือดีต่อสุขภาพมากขึ้นโดยอัตโนมัติ

## 5. หลักฐานด้านสุขภาพบอกอะไร? {#evidence}

องค์ประกอบสารอาหาร ผลที่พบในห้องปฏิบัติการ และประโยชน์ต่อสุขภาพที่พิสูจน์ในมนุษย์เป็นหลักฐานคนละประเภท ผลยังขึ้นกับว่าสิ่งที่ศึกษาเป็นใบ เมล็ดทั้งเมล็ด น้ำมัน หรือสารสกัดเข้มข้น

| ข้อกล่าวอ้าง | การประเมินหลักฐาน |
| --- | --- |
| อมารันท์ให้โปรตีนและแร่ธาตุ | มีข้อมูลองค์ประกอบรองรับ |
| ช่วยลดคอเลสเตอรอล | ผลการศึกษาในมนุษย์ขัดแย้งกัน ยังไม่ยืนยันประโยชน์อย่างน่าเชื่อถือ |
| ช่วยลดน้ำตาลในเลือด | มีข้อสังเกตเบื้องต้นที่น่าสนใจ แต่ยังไม่ใช่ผลการรักษาที่พิสูจน์แล้ว |
| ป้องกันมะเร็งหรือโรคหัวใจ | ยังไม่มีหลักฐานยืนยันในมนุษย์ |

### คอเลสเตอรอล: ผลการศึกษาในมนุษย์ไม่สอดคล้องกัน

การทดลองแบบสุ่มและปกปิดสองฝ่ายในปี 2010 มีผู้มีภาวะคอเลสเตอรอลสูงปานกลาง 22 คน รับประทานขนมอมารันท์สกัดไขมันหรือขนมข้าวโพดวันละ 50 g เป็นเวลา 2 เดือน การเปลี่ยนแปลงของคอเลสเตอรอลรวม LDL และไตรกลีเซอไรด์ไม่แตกต่างกันอย่างมีนัยสำคัญระหว่างกลุ่ม ส่วน HDL ลดลงมากกว่าในกลุ่มอมารันท์ (p = 0.03) งานวิจัยนี้ไม่ได้แสดงว่า LDL ลดลง Chávez-Jáuregui และคณะ, *Effects of defatted amaranth (Amaranthus caudatus L.) snacks on lipid metabolism of patients with moderate hypercholesterolemia*, Ciência e Tecnologia de Alimentos 30(4), 1007–1010 (2010), DOI [10.1590/S0101-20612010000400026](https://doi.org/10.1590/S0101-20612010000400026)

การทดลองแบบสุ่ม ปกปิดสองฝ่าย และสลับช่วงในปี 2019 มีผู้มีน้ำหนักเกินหรือโรคอ้วน 44 คน ใช้น้ำมันอมารันท์ 20 ml และน้ำมันเรพซีดในช่วงละ 3 สัปดาห์ โดยมีช่วงพักระหว่างการทดลอง การเปลี่ยนแปลงของคอเลสเตอรอลรวมและ LDL ระหว่างช่วงใช้น้ำมันอมารันท์แย่กว่าช่วงใช้น้ำมันเรพซีด (ทั้งสองค่า p = 0.002) ส่วนผลลัพธ์อื่นที่วิเคราะห์ รวมถึง HDL และไตรกลีเซอไรด์ ไม่แตกต่างกันอย่างมีนัยสำคัญ งานวิจัยนี้ไม่สนับสนุนการใช้น้ำมันอมารันท์เพื่อลดคอเลสเตอรอล Dus-Zuchowska และคณะ, *Amaranth Oil Increases Total and LDL Cholesterol Levels without Influencing Early Markers of Atherosclerosis in an Overweight and Obese Population*, Nutrients (2019), DOI [10.3390/nu11123069](https://doi.org/10.3390/nu11123069), PMID [31888234](https://pubmed.ncbi.nlm.nih.gov/31888234/) บทความปี 2021 วิเคราะห์ผู้เข้าร่วมชุดเดิม จึงไม่ใช่การทดลองอิสระ [DOI 10.3390/nu13082743](https://doi.org/10.3390/nu13082743)

รายงานเชิงสังเกตเบื้องต้นที่เผยแพร่ในปี 2026 พบว่าคอเลสเตอรอลรวม (212.16 ลดเป็น 197.03 mg/dL) และ LDL (133.4 ลดเป็น 123.86 mg/dL) ลดลงในช่วง 3 เดือนในผู้ใช้สารสกัดเมล็ด Amaranthus caudatus แต่การเปลี่ยนแปลงทั้งสองไม่มีนัยสำคัญทางสถิติ มีผู้เริ่มต้น 60 คน และมีข้อมูลผลลัพธ์เมื่อครบ 3 เดือน 37 คน จำนวนตัวอย่างแตกต่างกันตามการวิเคราะห์ ไม่มีกลุ่มควบคุมหรือยาหลอก ผู้เข้าร่วมได้รับคำแนะนำด้านอาหาร และ NatIng Italia ซึ่งเป็นผู้จัดหาสารสกัดให้ทุนและมีส่วนร่วมในการวิจัย วิเคราะห์ และตีความผล การเปรียบเทียบก่อนและหลังนี้ไม่ได้พิสูจน์ว่าสารสกัดเป็นสาเหตุของการเปลี่ยนแปลง Mattiello และคณะ, *Preliminary evaluation of an extract of Amaranthus caudatus as a novel nutraceutical: effects on cholesterol and glucose absorption*, Frontiers in Nutrition (12 ม.ค. 2026), DOI [10.3389/fnut.2025.1740097](https://doi.org/10.3389/fnut.2025.1740097)

### น้ำตาลในเลือด: ชนิดผลิตภัณฑ์และวิธีเตรียมมีผล

การศึกษาขนาดเล็กแบ่งสตรีวัยหมดประจำเดือน 90 คนเป็น 3 กลุ่ม กลุ่มหนึ่งได้รับผงใบอมารันท์แห้งวันละ 9 g เป็นเวลา 3 เดือน และมีรายงานว่าน้ำตาลขณะอดอาหารลดลง 10.4% ผลนี้น่าสนใจแต่เป็นการศึกษาเล็กในกลุ่มเฉพาะ ไม่ได้พิสูจน์ว่าผงใบใช้รักษาเบาหวานหรือให้ผลเดียวกันในคนกลุ่มอื่น [งานวิจัย](https://pubmed.ncbi.nlm.nih.gov/26396347/)

วิธีเตรียมอาหารอาจเปลี่ยนการตอบสนองของน้ำตาลได้ด้วย การศึกษาในปี 2015 ซึ่งมีอาสาสมัครสุขภาพดี 20 คน รายงานค่าดัชนีน้ำตาลที่ปรับแล้วเท่ากับ 45.9 สำหรับซีเรียลที่มีอมารันท์ 74.1 สำหรับซีเรียลเปรียบเทียบ และ 105.2 สำหรับอมารันท์พองเพียงอย่างเดียว ตัวเลขนี้ใช้กับอาหารที่ทดสอบและกลุ่มตัวอย่างขนาดเล็กเท่านั้น ไม่ใช่อมารันท์ทุกชนิด Schneider, Heinemann และ Hahn, *Comparison of Glycemic Index and Satiety of Cereals containing Amaranth*, Journal of Human Nutrition and Food Science 3(5), 1074 (2015), DOI 10.47739/2333-6706/1074 ([full text](https://www.jscimedcentral.com/journal-article-info/Journal-of-Human-Nutrition-and-Food-Science/Comparison-of-Glycemic--Index-and-Satiety-of-Cereals--containing-Amaranth-8443))

ในรายงานปี 2026 เดียวกัน ค่า HbA1c เฉลี่ยลดจาก 5.8 ± 0.4% เป็น 5.3 ± 0.6% และผู้เขียนรายงานว่าการเปลี่ยนแปลงของ HbA1c น้ำตาลหลังอาหาร และ BMI มีนัยสำคัญทางสถิติ ส่วนการเปลี่ยนแปลงของน้ำตาลขณะอดอาหารไม่มีนัยสำคัญ รูปแบบการศึกษาแบบไม่มีกลุ่มควบคุมและกลุ่มเปรียบเทียบไม่สามารถยืนยันเหตุและผลได้ งานวิจัยศึกษาสารสกัด ไม่ใช่อาหารอมารันท์ทั่วไป [รายงานการศึกษา](https://doi.org/10.3389/fnut.2025.1740097)

รายงานเดียวกันพบว่าการขนส่งกลูโคสและคอเลสเตอรอลลดลงในแบบจำลองลำไส้ นี่เป็นผลจากการทดลองในห้องปฏิบัติการ ไม่ใช่การลดน้ำตาลหรือคอเลสเตอรอลในเลือดคนในอัตราเดียวกัน

### สรุป

การศึกษาในมนุษย์ยังไม่ยืนยันอย่างน่าเชื่อถือว่าอมารันท์หรือน้ำมันอมารันท์ลดคอเลสเตอรอล ข้อสังเกตเรื่องน้ำตาลในเลือดยังเป็นข้อมูลเบื้องต้นและขึ้นกับผลิตภัณฑ์ที่ศึกษา เช่น ผงใบ สารสกัดเมล็ด ส่วนผสมธัญพืช หรือเมล็ดพอง อมารันท์รับประทานเป็นส่วนหนึ่งของอาหารที่หลากหลายได้ แต่ไม่ควรถือเป็นยา หรือใช้แทนการรักษาที่แพทย์สั่ง

### ข้อสังเกตจากประชากรในภูมิภาคต่าง ๆ และอายุขัย

มีการศึกษาการใช้และบริโภคอมารันท์ในหลายภูมิภาค แต่การศึกษาเหล่านี้ไม่ได้แสดงว่าการกินอมารันท์ช่วยยืดอายุ

- **เคนยาและแทนซาเนีย:** จากการสนทนากลุ่ม 20 กลุ่มและการสัมภาษณ์ผู้ให้ข้อมูลหลัก 20 ราย มีการกล่าวถึงอมารันท์ในกลุ่มผักใบพื้นเมืองที่นิยม 3 อันดับแรกในประมาณ 90% ของกลุ่มสนทนา ตัวเลขนี้สะท้อนความชอบของกลุ่มสนทนา ไม่ใช่สัดส่วนประชากรที่บริโภคหรือผลต่อสุขภาพ นักวิจัยรายงานว่าผู้คนมักรับประทานเพราะราคาไม่แพงและหาได้ง่าย [Nyonje และคณะ, 2022](https://pmc.ncbi.nlm.nih.gov/articles/PMC9233608/)
- **เม็กซิโก:** การสำรวจเกษตรกรผู้ปลูกอมารันท์ 70 รายในเมือง Tochimilco รัฐ Puebla พบว่า 77% ของครัวเรือนรายงานว่าไม่ได้บริโภคอมารันท์ การปลูกพืชในพื้นที่จึงไม่ได้แปลว่าคนในพื้นที่รับประทานเสมอไป [Corona-González และคณะ, 2019](https://www.scielo.org.mx/scielo.php?pid=S2395-91692019000200123&script=sci_abstract&tlng=en) หน่วยงานสาธารณสุขรัฐ San Luis Potosí รายงานว่าเด็ก 3,769 คนฟื้นตัวจากภาวะทุพโภชนาการในปี 2013 ภายใต้โครงการที่มีแป้งอมารันท์ร่วมด้วย รายงานนี้ไม่มีกลุ่มเปรียบเทียบ จึงไม่สามารถระบุว่าผลเกิดจากอมารันท์เพียงอย่างเดียว [หน่วยงานสาธารณสุขเม็กซิโก, 2014](https://www.gob.mx/salud/prensa/control-nutricional-a-menores-de-5-anos)
- **โครงการนำร่องขนาดเล็กในเม็กซิโก:** การศึกษาแบบไม่สุ่มในเด็ก 9 คนที่มีส่วนสูงต่ำกว่าเกณฑ์ ให้เมล็ดอมารันท์พองวันละ 4 g นาน 3 เดือน พบการเปลี่ยนแปลงของจุลินทรีย์ในลำไส้ รวมถึงสัดส่วนสัมพัทธ์ของวงศ์ Akkermansiaceae งานศึกษาจุลินทรีย์ขนาดเล็กนี้ไม่ได้พิสูจน์ประโยชน์ทางคลินิกหรือการมีอายุยืนขึ้น [งานวิจัยปี 2023](https://www.mdpi.com/2304-8158/12/14/2760)
- **เอธิโอเปีย:** การศึกษา 6 เดือนในเด็กอายุ 2–5 ปีที่มีภาวะโลหิตจางพบว่าขนมปังที่มีอมารันท์และถั่วชิกพีลดภาวะโลหิตจางเมื่อเทียบกับขนมปังข้าวโพด ผลิตภัณฑ์มีส่วนผสมหลายชนิดและผ่านกระบวนการเฉพาะ จึงระบุผลว่าเกิดจากอมารันท์อย่างเดียวไม่ได้ ผลนี้ใช้กับการแทรกแซงด้านอาหารและกลุ่มเด็กดังกล่าว ไม่ได้บอกเรื่องอายุขัย [Orsango และคณะ, 2020](https://pubmed.ncbi.nlm.nih.gov/32986748/)
- **เคนยา:** การศึกษา 16 สัปดาห์ในเด็กก่อนวัยเรียนพบว่าโจ๊กที่ทำจากอมารันท์และข้าวโพดไม่ได้เพิ่มฮีโมโกลบินหรือปรับสถานะธาตุเหล็กอย่างมีนัยสำคัญ ผลจึงแตกต่างกันตามผลิตภัณฑ์และรูปแบบการศึกษา [งานวิจัยใน PubMed](https://pubmed.ncbi.nlm.nih.gov/22810982/)
- **สหรัฐอเมริกา:** การศึกษาติดตามกลุ่มประชากรขนาดใหญ่พบความสัมพันธ์ระหว่างการบริโภคธัญพืชไม่ขัดสีโดยรวมที่มากขึ้นกับอัตราการเสียชีวิตโดยรวมและจากโรคหัวใจและหลอดเลือดที่ต่ำลง งานเหล่านี้ไม่ได้แยกผลของอมารันท์ จึงใช้ยืนยันไม่ได้ว่าอมารันท์เองช่วยยืดอายุ [Wu และคณะ, 2015](https://jamanetwork.com/journals/jamainternalmedicine/fullarticle/2087877)

**ข้อสรุปเรื่องอายุขัย:** ยังไม่มีการศึกษาติดตามประชากรระยะยาวที่น่าเชื่อถือซึ่งแสดงว่าการบริโภคอมารันท์ในปริมาณมากช่วยยืดอายุหรือลดการเสียชีวิต งานศึกษาการใช้ในแต่ละภูมิภาคบอกเล่าประเพณีอาหารและความพร้อมในการเข้าถึง ไม่ได้พิสูจน์ผลต่อสุขภาพด้วยตัวเอง รูปแบบอาหารโดยรวม รายได้ ความมั่นคงทางอาหาร และการเข้าถึงบริการสุขภาพล้วนมีผลต่อสุขภาพของประชากร

## 6. ความปลอดภัยและข้อควรระวัง {#safety}

### ออกซาเลต

ทั้งเมล็ดและใบมีออกซาเลต และใบของบางพันธุ์อาจมีปริมาณสูง ออกซาเลตจับกับแร่ธาตุได้และอาจเกี่ยวข้องกับความเสี่ยงในผู้ที่มีแนวโน้มเป็นนิ่วออกซาเลต การศึกษาสายพันธุ์อมารันท์เมล็ด 30 สายพันธุ์พบออกซาเลตเฉลี่ย 229 mg ต่อเมล็ด 100 g แต่ส่วนใหญ่เป็นรูปที่ไม่ละลายน้ำ ข้อมูลนี้ไม่ได้ยืนยันความเสี่ยงการดูดซึมเช่นเดียวกับออกซาเลตชนิดละลายน้ำ

การต้มใบที่มีออกซาเลตสูงและเทน้ำต้มทิ้งอาจช่วยลดออกซาเลต แต่ก็ทำให้สารอาหารที่ละลายน้ำบางส่วนสูญเสียไปด้วย

### ไนเตรต

ใบอมารันท์อาจสะสมไนเตรต โดยเฉพาะเมื่อใช้ปุ๋ยไนโตรเจนมากหรือสภาพการปลูกไม่สมดุล การต้ม ลวก และเทน้ำทิ้งช่วยลดปริมาณได้

ควรระมัดระวังเป็นพิเศษเมื่อนำไปทำอาหารสำหรับทารกและเด็กเล็ก ควรหลีกเลี่ยงการให้ใบอมารันท์ที่ปลูกเองในปริมาณมาก หากไม่ทราบระดับไนเตรต

### วิตามินเคและยา

ผู้ที่ใช้วาร์ฟารินและรับประทานใบอมารันท์ปริมาณมากควรรักษาปริมาณวิตามินเคในอาหารให้สม่ำเสมอ และปรึกษาบุคลากรทางการแพทย์ก่อนเปลี่ยนอาหารอย่างมีนัยสำคัญ

### โลหะหนัก

พืชในสกุล Amaranthus อาจสะสมสารปนเปื้อนในสิ่งแวดล้อม เช่น แคดเมียม การวิเคราะห์อภิมานพบว่าใบมีแนวโน้มสะสมแคดเมียมในดินปนเปื้อน ไม่ควรปลูกอมารันท์เพื่อรับประทานในดินถมที่ปนเปื้อน ริมรางระบายน้ำเสีย หรือบริเวณที่ได้รับผลจากน้ำเสียอุตสาหกรรม

อมารันท์เติบโตได้ในสภาพแวดล้อมหลายแบบ แต่ความทนแล้งไม่ได้หมายความว่าจะให้ผลผลิตสูงได้โดยไม่มีน้ำ

### เหตุใดอมารันท์จึงทนร้อน?

การสังเคราะห์แสงแบบ C4 ช่วยให้อมารันท์ตรึงคาร์บอนได้อย่างมีประสิทธิภาพในอุณหภูมิสูง ประสิทธิภาพการใช้น้ำอาจดีกว่าพืช C3 หลายชนิด จึงเป็นประโยชน์ในพื้นที่แดดจัดและมีการระเหยสูง

อย่างไรก็ตาม ความทนทานมีขีดจำกัด ความเครียดจากการขาดน้ำนานทำให้พื้นที่ใบและการเติบโตลดลง และอาจกระตุ้นให้ออกดอกก่อนเวลา ดินเค็มก็ลดผลผลิต และแต่ละพันธุ์ตอบสนองต่างกัน

## 8. การปลูกอมารันท์ในประเทศไทย {#thailand}

ประเทศไทยมีสภาพแวดล้อมที่เหมาะกับอมารันท์ การปลูกเพื่อเก็บใบทำได้ง่ายและรวดเร็วกว่าการปลูกให้เมล็ดแก่

### 8.1. ชื่อเรียกในภาษาไทย

ชื่อภาษาไทยที่ใช้เรียก ได้แก่ ผักโขม และ ผักขม

| ชื่อไทย | ความหมาย |
| --- | --- |
| ผักโขม | ชื่อทั่วไปของอมารันท์ที่รับประทานได้ |
| ผักโขมจีน | อมารันท์ใบแบบจีน มักเป็น A. tricolor |
| ผักโขมสวน | อมารันท์สวน |
| ผักโขมแดง | อมารันท์แดง |
| ผักโขมหนาม | อมารันท์หนาม |

ชื่อสามัญอาจไม่ได้ระบุชนิดพืชอย่างแม่นยำ ควรตรวจชื่อวิทยาศาสตร์เมื่อซื้อเมล็ดพันธุ์ รายชื่อพืชอาหารของหน่วยงานไทยระบุชนิดต่าง ๆ แยกกัน เช่น A. tricolor, A. viridis และ A. caudatus

### 8.2. ฤดูกาล

| ช่วงเวลา | สภาพการปลูก |
| --- | --- |
| พฤศจิกายน–กุมภาพันธ์ | มักปลูกง่ายกว่า ฝนหนักน้อย |
| มีนาคม–พฤษภาคม | อากาศร้อนขึ้น ต้องจัดการน้ำ |
| พฤษภาคม–ตุลาคม | ฤดูฝน การระบายน้ำและควบคุมโรคสำคัญมาก |

บริเวณกรุงเทพฯ และสมุทรปราการ ช่วงพฤศจิกายน–กุมภาพันธ์เหมาะสำหรับเริ่มทดลองปลูก ในฤดูฝน ความเปียกชื้นเป็นความเสี่ยงมากกว่าความร้อน

### 8.3. ปัญหาหลักในฤดูฝน: อากาศที่ราก

อมารันท์ทนแล้งแต่ไม่ทนน้ำขังนาน เมื่อดินอิ่มน้ำ ออกซิเจนไปถึงรากได้ยาก การเติบโตช้าลงและโรครากพบได้มากขึ้น แปลงยกสูงต้องมีทางระบายน้ำไปยังจุดที่ต่ำพอ คูระบายน้ำที่ไม่มีทางออกไม่ช่วยแก้ปัญหาน้ำท่วม หากพื้นที่น้ำท่วมซ้ำ ควรยกภาชนะหรือรางปลูกให้สูงกว่าระดับน้ำ

แนวทางของมหาวิทยาลัยฟลอริดาแนะนำแปลงสูงได้ถึงประมาณ 50 cm ในฤดูฝน สำหรับแปลงที่ระบายน้ำยาก การทดลองเริ่มต้นที่ความสูง 30–50 cm เป็นทางเลือกหนึ่ง

### 8.4. การปลูกแบบไฮโดรโปนิกส์

อมารันท์ปลูกในระบบไฮโดรโปนิกส์ที่ควบคุมได้ เช่น ระบบหมุนเวียนสารละลายธาตุอาหารหรือระบบน้ำหยดผ่านวัสดุปลูก ระบบเหล่านี้ควบคุมน้ำและธาตุอาหารได้ใกล้ชิด และหลีกเลี่ยงปัญหาดินปนเปื้อน

ในประเทศไทย สารละลายธาตุอาหารอาจร้อนเกินไป ทำให้ออกซิเจนละลายน้ำลดลงและเพิ่มความเสี่ยงโรคราก สำหรับการทดลองครั้งแรก ระบบวัสดุปลูกแบบง่ายจัดการได้ง่ายกว่าระบบ NFT ขนาดใหญ่ ควรใช้น้ำสะอาด เติมอากาศ และควบคุมอุณหภูมิ

## 9. แผนทดลองปลูกในประเทศไทย {#thailand-trial}

แปลงทดลองขนาด 10 m² อาจใช้เปรียบเทียบพันธุ์ ผลผลิต และความเสี่ยงในฤดูฝน โดยไม่ต้องลงทุนสูงในช่วงแรก

### รูปแบบแปลงทดลอง

| พื้นที่ | ประเภท | เป้าหมาย |
| --- | --- | --- |
| 5 m² | A. tricolor ใบเขียว | การเติบโตและผลผลิตใบ |
| 5 m² | A. tricolor ใบแดง | การเติบโต รสชาติ และสีใบ |

### ลำดับการปลูก

1. **พื้นที่:** เลือกจุดที่มีแดดและระบายน้ำดี ใช้วัสดุปลูกสะอาดและอุดมสมบูรณ์พอเหมาะ
2. **หว่านเมล็ด:** หว่านลึกประมาณ 0.5 cm แล้วถอนแยกให้ต้นห่างกัน 15–20 cm หากต้องการเก็บใบอ่อนครั้งเดียว อาจปลูกถี่กว่า
3. **ช่วงเริ่มต้น:** รักษาความชื้นให้สม่ำเสมอ ป้องกันฝนทำให้ผิวดินแน่นหรือทำให้รากขาดอากาศ
4. **เก็บเกี่ยวครั้งแรก:** มักเริ่มได้ประมาณ 25–35 วันหลังหว่าน ขึ้นกับขนาดต้น หรือเลือกเก็บใบและยอดอ่อนเป็นรายต้น
5. **เก็บเกี่ยวต่อ:** หากตัดแล้วให้แตกใหม่ ควรเหลือใบและจุดเจริญไว้เพียงพอ อาจเก็บรอบใหม่ได้ในเวลาประมาณ 2 สัปดาห์
6. **บันทึกผล:** ชั่งผลผลิตแต่ละครั้งและจดอายุปลูก การให้น้ำ สภาพอากาศ ศัตรูพืช และคุณภาพใบ

การทดลองในไทยที่เปรียบเทียบต้นกล้าอมารันท์รายงานผลผลิตประมาณ 0.28–0.60 kg ต่อตารางเมตรในรอบปลูกสั้นหนึ่งรอบ ขึ้นกับชนิด หากคำนวณที่อัตรานี้ พื้นที่ 10 m² จะได้ 2.8–6.0 kg ต่อการเก็บเกี่ยวหนึ่งครั้ง ตัวเลขนี้เป็นเพียงตัวอย่าง ไม่ใช่คำพยากรณ์สำหรับสวนใดสวนหนึ่ง พันธุ์ ความหนาแน่น อายุเก็บเกี่ยว และสภาพอากาศล้วนเปลี่ยนผลได้ และยังไม่รวมการตัดรอบถัดไป

การเปรียบเทียบอมารันท์ 8 สายพันธุ์ในไทยยังพบความแตกต่างด้านการเติบโตและองค์ประกอบสารอาหาร โดยสายพันธุ์ท้องถิ่น AS 129 ทำได้ดีเป็นพิเศษ จึงควรทดลองพันธุ์ที่ปรับตัวกับท้องถิ่นแล้ว

## 10. การปลูกอมารันท์เพื่อเมล็ดในประเทศไทย {#thailand-grain}

การผลิตเมล็ดต่างจากการเก็บใบเร็ว พืชต้องเติบโต ออกดอก ติดเมล็ด และแก่เต็มที่ หลายพันธุ์ใช้เวลาประมาณ 100–120 วันหรือนานกว่า และสูง 1–2.5 m ความเสี่ยงหลักคือฝน โรคเชื้อรา การล้ม และการทำให้ผลผลิตแห้ง การเก็บเกี่ยวมักต้องนวด ทำความสะอาด และตากหรืออบอย่างระมัดระวัง

อมารันท์บางพันธุ์ไวต่อช่วงแสง ซึ่งมีผลต่อเวลาออกดอกทั้งในเขตร้อนและเขตหนาว

### ควรปลูกเพื่อเก็บเมล็ดเมื่อใด?

ควรทดลองช่วงปลูกที่ทำให้เมล็ดแก่ในฤดูค่อนข้างแห้ง บริเวณกรุงเทพฯ อาจทดลองหว่านช่วงปลายปี ความท้าทายมักไม่ใช่การทำให้ต้นโต แต่เป็นการทำให้เมล็ดแห้งและสะอาดพอสำหรับเก็บรักษา แนวทางเกษตรของออนแทรีโอแนะนำทำความสะอาดเมล็ดและลดความชื้นเหลือประมาณ 8%

### ผลผลิตเมล็ดที่เป็นไปได้

ผลผลิตจากงานปลูกทดลองแตกต่างกันมาก ช่วงที่มักอ้างถึงคือประมาณ 500–2,000 kg ต่อเฮกตาร์ หรือราว 50–200 g เมล็ดแห้งต่อตารางเมตร มีรายงานผลผลิตสูงกว่านี้ในบางการทดลอง การเก็บด้วยมือในแปลงเล็กอาจใช้แรงงานมากเมื่อเทียบกับปริมาณเมล็ดที่ได้

## 11. การปลูกอมารันท์ในฟินแลนด์ {#finland}

ในฟินแลนด์ควรแยกเป้าหมายการปลูกใบออกจากการปลูกให้ได้เมล็ดแก่

### อมารันท์สำหรับใบ

การทดลองปลูกใบทำได้จริง ในฟินแลนด์ตอนกลางอาจเพาะต้นกล้าในบ้านช่วงเดือนพฤษภาคม แล้วค่อยย้ายลงดินอุ่นหลังพ้นความเสี่ยงน้ำค้างแข็ง ซึ่งมักเป็นช่วงต้นหรือกลางเดือนมิถุนายน การหว่านตรงทำได้เมื่อดินอุ่นแล้ว จุดปลูกที่อุ่น อุโมงค์ปลูก หรือเรือนกระจกช่วยเพิ่มโอกาส เก็บใบได้ในฤดูเดียวกันและปลูกในกระถางใหญ่ได้

### การผลิตเมล็ดยากกว่า

อมารันท์เมล็ดหลายพันธุ์ใช้เวลา 100–120 วัน ฤดูร้อนของฟินแลนด์อาจสั้นเกินไป และอากาศเย็นช่วงต้นฤดูทำให้การเติบโตช้า ความไวต่อช่วงแสงอาจทำให้ออกดอกช้าในพื้นที่เหนือ การเลือกพันธุ์ที่แก่เร็วและตอบสนองต่อช่วงแสงน้อยจึงสำคัญ

บริเวณ Luhanka ควรเริ่มจาก 5–10 ต้นในจุดอุ่นและมีที่กำบัง แทนการปลูกแปลงใหญ่ แนวทางของออนแทรีโอก็เน้นดินอุ่น ฤดูปลูกที่ไม่มีน้ำค้างแข็ง และการทำเมล็ดให้แห้งอย่างเหมาะสม

## 12. ศัตรูพืชและโรคพืช {#pests}

บางครั้งมีการเรียกอมารันท์ว่าเป็นพืชที่แทบไม่มีปัญหา ซึ่งเกินจริง ปัญหาอาจรวมถึงหนอนกินใบ เพลี้ยอ่อน ด้วงกินใบ โรคเน่าคอดิน และโรครากหรือโรคลำต้น

ในเขตร้อน ความชื้นสูงและปลูกแน่นเกินไปอาจทำให้โรคเชื้อรารุนแรงขึ้น การปลูกพืชชนิดเดิมซ้ำที่เดิมเพิ่มแรงกดดันจากศัตรูพืชและโรค การระบายน้ำดี การถ่ายเทอากาศ เมล็ดพันธุ์แข็งแรง การกำจัดเศษพืช และการหมุนเวียนพืชเป็นแนวทางหลัก ควรใช้สารกำจัดศัตรูพืชเมื่อยืนยันแล้วว่าผลิตภัณฑ์ได้รับอนุญาตกับพืชอาหารชนิดนั้นในประเทศที่ปลูก

## 13. รสชาติและการนำไปใช้ {#taste}

### ใบ

ใบอ่อนมักมีรสอ่อนคล้ายผักโขมและมีรสกลิ่นดินเล็กน้อย ใบแก่จะเหนียวขึ้น และพันธุ์ใบแดงอาจทำให้น้ำต้มมีสี

ในประเทศไทยสามารถผัดใบอมารันท์กับกระเทียม ใส่แกงจืด ไข่เจียว หรือปรุงร่วมกับผักชนิดอื่นได้ นึ่งก็ได้เช่นกัน หากใบมีออกซาเลตสูง การต้มและเทน้ำทิ้งช่วยลดออกซาเลตได้

### เมล็ด

</figure>

เมล็ดมีรสอ่อน คล้ายถั่ว และมีกลิ่นดินเล็กน้อย ใช้ทำโจ๊ก ซุป แผ่นผัก แป้งผสม หรือคั่วและทำให้พองได้

เมล็ดต้มมักนุ่มและเหนียวเล็กน้อย เพราะเมล็ดขนาดเล็กและแป้งรวมตัวกัน หากทำโจ๊ก ลองใช้อัตราเมล็ด 1 ส่วนต่อน้ำ 2.5–3 ส่วน เคี่ยวประมาณ 20–30 นาที

แป้งอมารันท์ไม่มีโครงข่ายกลูเตน จึงมักต้องผสมแป้งชนิดอื่นหรือสารช่วยให้ขนมมีโครงสร้าง ผู้เป็นโรคเซลิแอคควรเลือกผลิตภัณฑ์ที่ระบุว่าปราศจากกลูเตน เพราะอาจมีการปนเปื้อนข้ามระหว่างบดและบรรจุ

## 14. ศักยภาพเชิงพาณิชย์ {#commercial}

อมารันท์อาจมีศักยภาพทางการค้า แต่โอกาสแตกต่างกันตามประเภทผลิตภัณฑ์

| ผลิตภัณฑ์ | ความยากในการผลิต | ตลาดที่อาจเป็นไปได้ |
| --- | --- | --- |
| ใบสด | ต่ำ–ปานกลาง | จำหน่ายอาหารในท้องถิ่น |
| ใบแดงพันธุ์พิเศษ | ต่ำ–ปานกลาง | ร้านอาหารและตลาดผักพิเศษ |
| ไมโครกรีน | ปานกลาง | รอบปลูกสั้น แต่ต้องควบคุมสุขอนามัยเข้มงวด |
| เมล็ดแห้ง | ปานกลาง–สูง | อาหารปราศจากกลูเตนและอาหารเฉพาะกลุ่ม |
| แป้งอมารันท์ | ปานกลาง–สูง | การแปรรูปอาหาร |
| น้ำมันอมารันท์ | สูง | ผลิตภัณฑ์เฉพาะกลุ่มมูลค่าสูง |
| การสกัดสควาลีน | สูงมาก | วัตถุดิบเฉพาะทางอุตสาหกรรม |
| สีแดงธรรมชาติ | สูง | การพัฒนาอาหารและสี |

นี่เป็นการประเมินเชิงคุณภาพ ไม่ใช่การเปรียบเทียบจากราคาตลาดหรือผลกำไรที่พิสูจน์แล้ว

### ไมโครกรีนเป็นทางเลือกกึ่งกลาง

ไมโครกรีนอมารันท์เก็บเกี่ยวได้เมื่ออายุประมาณ 10–18 วัน และปลูกในระบบขนาดเล็กได้ งานวิจัยไทยปี 2026 เปรียบเทียบยอดอมารันท์แดงอายุเก็บเกี่ยว 7, 10 และ 14 วัน พบว่าผลผลิตและองค์ประกอบทางเคมีเปลี่ยนตามอายุเก็บเกี่ยว จึงอาจเหมาะกับการผลิตผักพิเศษขนาดเล็ก แต่ต้องควบคุมสุขอนามัยอย่างเข้มงวด โดยเฉพาะเมื่อรับประทานดิบ

### เศรษฐศาสตร์ของการผลิตสควาลีน

น้ำมันอมารันท์น่าสนใจเพราะมีสควาลีน แต่เมล็ดมีน้ำมันเพียงไม่กี่เปอร์เซ็นต์ หากเมล็ดหนึ่งตันมีน้ำมัน 5% และน้ำมันนั้นมีสควาลีน 4.2% จะได้สควาลีนตามทฤษฎีประมาณ 2.1 kg ปริมาณที่สกัดได้จริงจะน้อยลงเพราะการสูญเสียระหว่างกระบวนการ นี่ทำให้การสกัดสควาลีนระดับอุตสาหกรรมซับซ้อนกว่าการขายใบหรือเมล็ดมาก

## 15. อมารันท์ในฐานะพืชอาหารแห่งอนาคต {#future}

อมารันท์มีคุณสมบัติที่น่าสนใจต่อเกษตรที่ปรับตัวกับสภาพภูมิอากาศ เช่น การสังเคราะห์แสงแบบ C4 ความทนแล้ง การปลูกได้ในดินหลายแบบ และการใช้เป็นอาหารได้หลากหลาย ความหลากหลายทางพันธุกรรมยังช่วยให้มีโอกาสพัฒนาพันธุ์ดีขึ้น

พันธุ์ปัจจุบันแตกต่างกันมากในเรื่องเวลาออกดอก ผลผลิต ความทนร้อนและความเค็ม รวมถึงองค์ประกอบสารอาหาร การปรับปรุงพันธุ์จึงสำคัญพอ ๆ กับการศึกษาสารอาหาร อมารันท์ยังไม่ได้รับการพัฒนาด้านการเพาะปลูกในระดับเดียวกับข้าวสาลีหรือข้าว

เป้าหมายที่น่าสนใจ ได้แก่ พันธุ์เมล็ดที่แก่เร็ว พันธุ์ใบที่ทนน้ำขังได้ดีขึ้น พืชอาหารที่มีออกซาเลตต่ำลง และสายพันธุ์ที่ให้น้ำมันหรือเบตาเลนสูงขึ้น

## 16. การประเมินโดยรวม {#assessment}

การประเมินเชิงบรรณาธิการเกี่ยวกับคุณสมบัติของพืช ไม่ใช่การจัดอันดับทางวิทยาศาสตร์หรืออย่างเป็นทางการ

| หัวข้อ | คะแนน |
| --- | ---: |
| คุณค่าทางโภชนาการ | 4.5 / 5 |
| ความหลากหลายในการใช้ | 5.0 / 5 |
| ความทนร้อน | 4.5 / 5 |
| การปลูกในประเทศไทย | 4.5 / 5 |
| การปลูกในฟินแลนด์ (ใบ) | 3.5 / 5 |
| การปลูกในฟินแลนด์ (เมล็ด) | 2.0 / 5 |
| ผลสุขภาพเฉพาะที่พิสูจน์แล้ว | 1.5 / 5 |

อมารันท์เป็นหนึ่งในกลุ่มพืชอาหารที่ยังใช้ประโยชน์ไม่เต็มที่และน่าสนใจ โดยเฉพาะการทดลองปลูกในประเทศไทย จุดแข็งไม่ได้อยู่ที่สารมหัศจรรย์ชนิดเดียว แต่อยู่ที่การผสมผสานคุณสมบัติด้านโภชนาการ ชีววิทยา และการเพาะปลูก

### ประเด็นที่ควรศึกษาเพิ่มเติม

ควรทดลองว่าพันธุ์ใดในไทยให้ผลผลิตใบและคุณภาพดีที่สุด สภาพการปลูกมีผลต่อออกซาเลตและรงควัตถุอย่างไร และแปลงยกสูงหรือระบบไฮโดรโปนิกส์จะผลิตได้สม่ำเสมอตลอดปีหรือไม่ คำถามเหล่านี้เป็นแนวทางวิจัยที่ทำได้จริงกว่าการมองอมารันท์เป็นยาครอบจักรวาล
